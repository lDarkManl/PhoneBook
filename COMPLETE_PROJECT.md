# PhoneBook - Полная документация проекта 🎉

## ✅ Все страницы реализованы!

### 1. Главная страница (/)
**Функционал:**
- Поиск преподавателей с фильтрами (ФИО, должность, подразделение, аудитория)
- Кнопка "Экспорт в Excel"
- Блок с деканами факультетов (ФИО, должность, подразделение, аудитория, телефоны)
- Блок с ближайшими мероприятиями (фото, название, дата, место, организатор)

### 2. Страница "Сотрудники" (/employees/)
**Функционал:**
- Поиск по ФИО
- Фильтры: ФИО, должность, ученая степень
- Сортировка по возрастанию (А-Я) и убыванию (Я-А)
- Кнопка "Экспорт в Excel"
- Карточки сотрудников с информацией о должностях и контактах
- Детальная страница сотрудника с полной информацией

### 3. Страница "Подразделения" (/subdivisions/)
**Функционал:**
- Список только факультетов (без кафедр)
- Для каждого факультета:
  - Название, тип, расположение
  - Фото и информация о декане (ФИО, должность, телефоны)
  - Количество кафедр и сотрудников
- Кнопка "Экспорт в Excel"
- При клике на факультет → переход на страницу "Дерево подразделений"

### 4. Страница "Дерево подразделений" (/subdivisions/{id}/tree/)
**Функционал:**
- Информация о выбранном факультете и декане
- Список всех кафедр факультета
- Для каждой кафедры:
  - Название, тип, аудитория
  - Фото и информация о заведующем кафедрой
  - Количество сотрудников
- Breadcrumb навигация
- Кнопка "Назад к факультетам"

### 5. Страница "Аудитории" (/rooms/)
**Функционал:**
- Поиск аудитории по корпусу и номеру
- Бургер-меню с фильтром по корпусу университета
- После поиска отображается:
  - **Расписание занятий** (по дням недели):
    - Время начала - время конца
    - Название предмета
    - Тип занятия (Лекция, Практика, Лабораторная работа)
    - Имя преподавателя (с ссылкой на профиль)
  - **Мероприятия**:
    - Время начала - время конца
    - Тип мероприятия
    - Название и организатор

## Структура базы данных

### Основные модели:

**Accounts:**
- Role - роли пользователей

**Employees:**
- Employee - сотрудники (ФИО, ученая степень, роль)

**Structure:**
- TypeDivision - типы подразделений (Факультет, Кафедра, Лаборатория)
- Location - аудитории (корпус, номер)
- Subdivision - подразделения (с иерархией через parent)

**Positions:**
- Post - должности (Декан, Заведующий кафедрой, Профессор и т.д.)

**Contacts:**
- EmployeeDivision - связь сотрудников с подразделениями и контакты

**Events:**
- TypeEvent - типы мероприятий
- Event - мероприятия (название, дата, место, организатор, фото)

**Schedule (новое):**
- Subject - предметы
- LessonType - типы занятий (Лекция, Практика, Лабораторная работа)
- Schedule - расписание занятий (предмет, тип, преподаватель, аудитория, день недели, время)

## Запуск проекта

```bash
# Запустите сервер
python manage.py runserver

# Откройте в браузере
http://127.0.0.1:8000/
```

## Доступные URL

- **Главная**: http://127.0.0.1:8000/
- **Сотрудники**: http://127.0.0.1:8000/employees/
- **Факультеты**: http://127.0.0.1:8000/subdivisions/
- **Дерево подразделений**: http://127.0.0.1:8000/subdivisions/1/tree/
- **Аудитории**: http://127.0.0.1:8000/rooms/
- **API**: http://127.0.0.1:8000/api/
- **Админка**: http://127.0.0.1:8000/admin/

## Экспорт в Excel

Кнопки экспорта доступны на всех основных страницах:
- **Главная** → экспорт всех сотрудников с контактами
- **Сотрудники** → экспорт сотрудников с должностями и контактами
- **Подразделения** → экспорт факультетов с деканами
